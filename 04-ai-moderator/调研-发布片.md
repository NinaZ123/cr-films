## 一、Higgsfield《Content Factory》怎么做的
抽帧：`ref/launch/hf-sheet.jpg`（每秒一帧），`hf-open.jpg`（开头 12 秒，每秒 4 帧）。

| 时间 | 画面 | 文字 |
|---|---|---|
| 0–4s | **直接放一个"产品做出来的成品"**：3D 卡通小人吃汉堡，头越吃越大 | 顶部大字 **WHAT IF** + 小字"a human could eat endlessly?" |
| 4–5s | 小人的头大到撑满画面，**大字从画面里冲出来**：荧光黄绿 3D 立体字 **CONTENT FACTORY**，带爆炸碎片 | 品牌名 |
| 5–6s | 字母翻转、拉伸，转场进下一个成品 | |
| 6–10s | 第二个成品：真人自拍，"What if your teeth never stopped growing?" | 字幕 |
| 10–12s | **白底 UI 动画**：模板名逐个滚动（VIRAL REEL / WHAT IF / HOOK AD），粉色输入框打出提示词 | 演示"怎么用" |
| 12–40s | 一个接一个成品，每个 3–5 秒；手机竖屏框嵌在横屏场景里 | 功能大字压在画面角落：**EVERY VIRAL PRESET FROM ONE CLICK** / **FULLY CODE-BASED VIDEOS IN ANY STYLE** / **READY-MADE HOOKS FOR YOUR ADS** |
| 40–50s | 播放量数字飞出来（12.5M / 3.8M / 1.3M），一排排卡片 | 证明效果 |
| 50–62s | 小短剧：两个学生看到这个 hook，"I can make a better one." "Then do it." | 结尾 CTA：TRY HIGGSFIELD CONTENT FACTORY NOW |

**要点**
1. **开头 1 秒就是成品**，不铺垫。先让观众被画面抓住，第 4 秒才出品牌名。
2. **品牌名是一次"爆炸"**：巨大的 3D 立体字，品牌色，从画面中心冲出来，配一个重低音。这就是它的"招牌动画"。
3. **功能说明是三句短口号**，全大写、粗体，放在画面角落，不挡主体。每句 4–6 个词。
4. **真实感靠"成品"堆出来**：十几个真实做出来的视频快速闪过，比说明文字有说服力得多。
5. 节奏非常快，平均 2–3 秒一个镜头，音乐卡点。

## 二、MiniMax《Meet Max》怎么做的
抽帧：`ref/launch/mm-max-sheet.jpg`；关键帧 `mm-max-16.jpg`。

| 时间 | 画面 | 旁白（AI 第一人称） |
|---|---|---|
| 0–4s | 黑底，绿色代码雨，中间一个线框大脑在发光 | "System initialized. Allow me to introduce myself. I am Max." |
| 4–9s | 线框电脑写着 MAX → 线框手掌，大字 **MINIMAX AGENT**、**Full-Stack Engine** | "I am the world's first full-stack agent…" |
| 9–14s | 能力卡片逐张飞入：Supabase / Stripe / Cron jobs，霓虹描边 | "I use Supabase, handle Stripe, run cron jobs…" |
| 14–45s | **三个用户案例**。每个都是：左边用户的真人小窗（带声波和字幕）说需求 → 右边浮出一张张 UI 卡片，网站一步步搭起来 | "A Wall Street founder messaged me… I built it while he slept." |
| 45–49s | 所有案例的卡片散布成一片星云 | "Tell me what's on your mind… I'm Max. You're welcome." |
| 49–53s | 黑底 logo | |

**要点**
1. **AI 自己说话**：第一人称旁白，有个性（"You're welcome."），让一个"功能"变成一个"角色"。
2. **品牌母题贯穿全片**：绿色代码雨从头到尾都在背景里。
3. **真人画面放在小框里**，旁边配声波和字幕，再旁边是 AI 干活的 UI。**这跟我们要的"AI 主持人加受访者"几乎是同一个构图。**见 `mm-max-16.jpg`。
4. 结构是"我是谁 → 我能做什么 → 三个真实案例 → 召唤用户"。

## 三、MiniMax《Hailuo 02》怎么做的
抽帧：`ref/launch/mm-hailuo02-sheet.jpg`。
- 全片是一个主题世界（马戏团），一个接一个生成镜头，每个 2–3 秒，左下角小字写着提示词。
- 片名 **Hailuo 02** 在第 10 秒左右压在一个特写上出现，字很细、很克制。
- 结尾一句台词 "This is the moment you've waited for"，然后出 logo。
- 适合"模型发布"，靠画质说话。我们是功能发布，参考价值比前两支小。

## 四、对我们的启发
1. **开头 1 秒就要上真东西**，不能从黑场慢慢铺。我们的"真东西"就是一场正在进行的访谈：AI 正在追问，受访者正在回答。
2. **品牌名要做成一次爆炸**：像 Higgsfield 那样，大到撑满屏幕的品牌色立体字，配重低音。我们的版本是小幽灵像素炸开，聚成 **TURING TEST PASSED**。
3. **构图直接学《Meet Max》**：受访者的真人小窗带声波和字幕，旁边浮出 AI 主持人的追问卡片，背景是贯穿全片的品牌母题（我们用像素网格加小幽灵）。这样也解决了"不想让 Tavus 的脸太大、太居中"的问题，主持人就是一张卡片里的小窗。
4. **功能说明用三句全大写短口号**，压在画面角落。
5. **可以考虑让 AI 主持人自己说话**，第一人称旁白，像 Max 那样："I'm the first AI moderator to pass the Turing test. I listen. I follow up. I never read a script." 这一点要你来定。
