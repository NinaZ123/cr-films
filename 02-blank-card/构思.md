# 《空白卡》BLANK CARD：构思与分镜（待 XD 确认）

## 一句话
一个按日程活着的世界里，送卡的女孩捡到一张空白的命运卡，她决定把它留给自己。

## 理解
| XD 要点 | 片里怎么落 |
|---|---|
| TVA 的画面 | 「连续局」：没有尽头的琥珀色办公大厅，米色 CRT、气动管道、档案架、橡皮图章、一排排一样的桌子。暖黄、墨绿、橙色，带官僚主义的复古感。 |
| 2B 的唯美 | 白色的仿生人职员和执法者：瓷白外壳、黑色面罩，动作优雅安静。追逐中档案架碎成白色粒子，像花瓣一样散开。 |
| 机器人与粒子 | 仿生人职员；卡片和档案化成发光的点阵粒子；最后的门由粒子构成。 |
| 早期计算机艺术 / 神经漫游者 | 穿孔卡就是命运的载体；"越界"段走进线框矢量空间，有绿色荧光网格、ASCII 字符瀑布、80 年代 CG 风格的线框隧道。 |
| 二次元女主 | 07 号信差 Seven：黑色不对称波波头带一缕橙色挑染，米白复古耳机（卷线），墨绿 MA-1 夹克，橙色内衬，肩章写着 07。表情冷静，不卖萌。 |
| 朋克 / 自由 | 她在规定之外戴耳机听歌，这是整个大厅里唯一没被排进日程的东西。耳机后来成了她改变对手的方式：没有用暴力，靠的是"给出一点自由"。 |
| 积极、古典、不矫情 | 坎贝尔英雄旅程的压缩版：日常 → 召唤 → 拒绝/抉择 → 跨越门槛 → 考验 → 最大的对手 → 回报 → 新世界。结尾是行动（戳下第一个孔，往前走），不是落泪。 |
| 和《回响》的区别 | 《回响》向后看，是独自一人的伤感回忆。这部向前看，讲的是选择和行动，节奏明快，有对手、有同伴，结局是一个开始。 |

## 规格
- 约 95 秒，1920×1080，16:9，24fps，24 个镜头加片名。
- 画风统一为平面赛璐珞加 80 年代 OVA 质感（细网点、柔和的胶片颗粒），不追求写实。
- 声音：合成器加芯片音乐（方波、锯齿、鼓机），从安静的机械节拍一路升到朋克能量；终端的蜂鸣、盖章、管道气流等音效由我用程序合成。没有对白，全片只有一行终端字幕。

## 分镜（暂定）
**第一幕 · 日程（0–28s）**
1. 大远景：连续局大厅，档案架一直延伸到消失点，上千台 CRT 发着琥珀色的光。
2. 特写：瓷白的仿生人手给穿孔卡盖章，咚的一声。
3. 中景：气动管道里，胶囊嗖地射过。
4. Seven 登场：踩着滑板滑过桌子之间的过道，夹克飘起来，耳机里漏出一点旋律。
5. 特写：她的眼睛半闭着，跟着节拍轻轻点头。周围的仿生人动作完全同步，只有她不在拍子上。
6. 她从管道口接住胶囊，单手拧开，熟练地分拣。

**第二幕 A · 召唤（28–45s）**
7. 胶囊里滑出一张卡：上面一个孔都没有，在琥珀光里泛白。
8. 终端屏幕一个接一个变红，闪出 `UNSCHEDULED`（全片唯一的字幕）。
9. 整个大厅的仿生人同时停下，齐刷刷转头看向她。
10. 她低头看卡，再抬头，把卡塞进夹克内袋，拉上拉链。这就是她的选择。

**第二幕 B · 考验（45–75s）**
11. 执法仿生人从高处落下：白色修长，黑色面罩，像 2B 那样优雅。
12. 追逐：她踩着滑板冲过档案走廊，身后的档案架倒塌，碎成白色粒子。
13. 她跳进气动管道，被吸进去。
14. 管道外的世界线框化：绿色矢量网格隧道，她化成像素再重组。
15. ASCII 字符瀑布，她在字符瀑布间下坠、翻转。
16. 落进一片空旷的白色空间，中间立着一扇粒子组成的门。
17. 执法仿生人已经站在门前。两人对峙。
18. 她没有动手，摘下耳机递过去。
19. 仿生人迟疑着戴上耳机，面罩的显示屏上第一次跳出声波。
20. 它侧身让开。

**第三幕 · 新世界（75–95s）**
21. 她把空白卡插进门缝，门化成光。
22. 门外是真正的天空：她站在巨大建筑的边缘，日出，风把夹克吹得猎猎作响。
23. 特写：她用夹克上的金属别针，在卡上戳下第一个孔。
24. 远景：她往前走，仿生人戴着耳机跟在后面半步，两人走向地平线。
25. 片名：空白卡 / BLANK CARD。

## 制作方法
1. 主角和执法仿生人各做一张定妆设定表（三视图加头像），检查一致性后定稿。
2. 每个有人物的镜头，都用定妆图作为参考图去编辑出关键帧，不只靠文字描述。
3. 视频主力用 kling-v3-turbo 图生视频。粒子、线框这类无人镜头可以试 seedance。
