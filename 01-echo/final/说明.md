# 《回响》ECHO：虚构电影预告片

成片：`final/echo_trailer.mp4`，81.8 秒

## 故事
一个五十来岁的男人坐夜车回到下雨的北方旧城，走进废弃的红星剧院。空荡的观众席里响起一首老歌，舞台上一台旧录音机自己转了起来。歌是他二十出头时在这个台上唱的。
之后的片段一个接一个：年轻的他在台上弹吉他，满座的观众，最后一排一个穿浅色风衣、看不清脸的人；放映机自己亮起，年轻的他在夜雨里狂奔，追光打在空舞台上；化妆间的镜子里照出年轻的自己；那个人就坐在他身后一排。
他猛地回头，声音全停，黑场。一排空座位里，唯一放下的那张椅子慢慢弹了回去，像刚有人站起来。片名出现。
片子不交代那个人是谁、那年发生了什么、他为什么再没回来。

## 规格
- 1920×1080 H.264，24fps。画面 2.39:1 加黑边，有效区域 1920×804。AAC 立体声 48kHz，整体响度 −14.4 LUFS，峰值 −1.2 dBFS。
- 用了 21 个镜头加 2 张字幕卡和片名。结构：安静段，歌声段，96 BPM 摇滚快切段（每个剪点卡在拍子上），黑场静音，收尾。
- 调色：去饱和，暗部偏青、高光偏琥珀，暗角，胶片颗粒。

## 模型和流程
1. **定妆照**：gemini-3-pro-image 出了一张中年男人的定妆照（虚构人物）。同时比了 nano-banana-beta 和 gemini-3-pro-image-preview，选了 gemini-3-pro-image 这版。
2. **年轻版**：拿定妆照去编辑，同样比了三个模型，选 gemini-3-pro-image。脸型、眼睛、眉毛上的疤都保留了下来。
3. **关键帧**：22 张。有人物的镜头都把对应年龄的定妆照作为参考图去编辑，没有只靠文字描述的。我逐张看过，重做了 4 张：年轻版显老、笑容太假、镜子里照出来的不是年轻的他、录音机上有品牌字样。
4. **视频**：kling-v3-turbo-image-to-video，1080p 档，实际出片 2208×936。用关键帧当首帧，每条视频抽首、中、尾三帧检查人物和画面有没有走样。
   - 选它是因为和 minimax-h3、seedance 并排比过，它最清楚、最稳。
   - 椅子弹回去那个镜头，kling 没做出动作。改用 seedance-2.0-fast 首尾帧：首帧是椅子放下，尾帧是椅子收起（尾帧用 gemini-3-pro-image-preview 编辑出来）。
5. **声音**：
   - 那首歌：seedance-2.0-fast 文生视频顺带生成的音轨，只取音频。和 veo3.1-fast、kling、minimax、wan、happyhorse 生成的版本对比后选的。
   - 雨声和剧院空间声：veo3.1-fast 的音轨。
   - 摇滚配乐（失真吉他、贝斯、鼓，E 小调）和撞击声、低频轰鸣、椅子的闷响：都是我用程序合成的（`scripts/audio.py`）。
   - 镜头自带的音效：火车、开门、放映机、追光这几处用了视频模型自带的音轨。
6. **剪辑、调色、字幕、混音**：ffmpeg 加 Python。剪辑表在 `scripts/edl.py`，可以改了重出。

## 不满意的地方
- **声音我没法用耳朵听。** 混音只靠响度曲线和频谱分析来校。那首歌的旋律好不好听、中文歌词是不是含糊的伪中文、合成的摇滚是不是够"真"，都需要人听一遍。最可能露怯的是那首歌和摇滚段。
- 年轻版在不同镜头里大体是同一个人，但脸型略有浮动。奔跑那个镜头最明显，脸偏瘦长。
- 带人物的镜头只能用 kling，所以镜头运动都偏保守：推拉多，几乎没有大幅度运镜。
- 剧院有两种建筑风格：s05 是欧式穹顶大厅，后面几个镜头是朴素的国营剧场。可以解释成"记忆里的"和"现在的"，但不是刻意设计的。
- 片中出现的招牌和霓虹文字（"红星剧院""宾馆"）是模型生成的，局部有错字或缺笔画。

## CR 上遇到的、和 skill 文档不一致的情况
- **minimax-h3 不再接受本地图片。** skill 说 minimax 能直接用本地文件，实测 image-to-video 和 reference-to-video 收到 data URI 都直接返回 HTTP 400 "Invalid video parameters for the selected model"，换成 HTTP URL 就成功。request_id 示例：`01a1309d-a497-73a3-9345-a5cd4fef2391`、`01a130a0-1e83-7c32-b629-6ed9ae35d4ed`。记录在 `vid/t-*.json`。
- **找到一个没写进文档的上传接口 `/unified/v1/assets`**，但对试过的所有视频模型都返回 "Model has no portrait material primary route"，用不了。
- **最后的做法**：把关键帧原样交给 gemini-3-pro-image-preview 再"复刻"一遍。这个模型返回的是上游对象存储上的签名链接，有效期大约 12 小时，再拿这个链接当首帧。我没有把任何素材上传到 CR 以外的地方，这些链接是 CR 自己返回的。复刻前后我比过，画面几乎没变。
- **seedance 拦写实人脸。** 有真人脸的首帧，seedance 一律返回 content_policy_violation；满座观众的镜头也被拦了。没有人脸的镜头可以用。
